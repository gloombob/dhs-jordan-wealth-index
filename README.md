# dhs-jordan-wealth-index
Das Repository enthält R-Skripte sowie genutzte Quellen für die Posterpräsentation zur jordanischen DHS Survey aus 2023. 
- references.txt: Referenzen genutzter Quellen
- jordan.R: data cleaning, Berechnung der direkten und Fay-Herriot Schätzer
- plots.R: Code für ggplot-Karten für den Vergleich von direkten und Fay-Herriot Schätzern sowie Vergleich der CVs
- plots: Alle auf dem Poster genutzten Plots
